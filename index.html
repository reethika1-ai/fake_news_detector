Bidirectional Recurrence

Simultaneous forward ($\vec{h}_n$) and backward ($\overleftarrow{h}_n$) sequence reading captures qualifying clauses that appear late in clickbait headlines.

Negation Disambiguation

Bag-of-words models confuse "not a hoax" with "is a hoax". BiLSTM preserves token order, correctly classifying negated claims.

Regularized 50-Epoch Convergence

Dropout ($p=0.3$) and learning rate scheduling prevented overfitting across 50 epochs, achieving stable generalizability without parameter explosion.

Deployment & Configuration Quick Guide

1. Model Placement

The scratch-built PyTorch BiLSTM weights trained for 50 epochs reside in the model/ folder as best_model.pt.

2. Supabase Table Creation

Run the SQL script from schema.sql in your Supabase SQL Editor:

CREATE TABLE IF NOT EXISTS public.prediction_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    news_text TEXT NOT NULL,
    prediction VARCHAR(50) NOT NULL,
    confidence NUMERIC(5, 2) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

3. Environment Variables

Configure .env in your root project directory:

SUPABASE_URL="https://your-project.supabase.co"
SUPABASE_KEY="your-anon-or-service-role-key"
