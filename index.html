Deployment & Configuration Quick Guide

1. Model Placement

Place your fine-tuned PyTorch DistilBERT weights file inside the model/ folder named best_model.pt.

2. Supabase Table Creation

Run the SQL script from schema.sql in your Supabase SQL Editor:

CREATE TABLE IF NOT EXISTS public.prediction_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    news_text TEXT NOT NULL,
    prediction VARCHAR(50) NOT NULL,
    confidence NUMERIC(5, 2) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

3. Environment Variables

Set these in your .env file or Vercel Environment Variables dashboard:

SUPABASE_URL="https://xyzcompany.supabase.co"
SUPABASE_KEY="your-anon-or-service-key"
